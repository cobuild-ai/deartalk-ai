## 📌 상태 표기 규칙 (Status Protocol)
- `- [ ]`: **대기 중 (Pending)** - AI가 다음 루프에서 우선적으로 구현합니다.
- `- [?]`: **질문/설계 확인 필요 (Clarification Needed)** - 요청이 모호하거나 모순되어 AI가 소스코드를 건드리지 않고 아래에 옵션(A/B)을 남겨둔 상태입니다. 내용을 확인 후 원하는 옵션을 남기고 `- [ ]`로 바꿔주시면 다음 루프에서 진행됩니다.
- `- [x]`: **완료됨 (Completed)** - AI가 구현 및 테스트를 완료하고 브랜치에 푸시한 상태입니다.
