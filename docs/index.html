  • 광고 및 추적 SDK 제로: 외부 광고 프레임워크, 사용자 행동 분석(Analytics), 진단 트래킹 SDK가 전혀 포함되어 있지 않습니다.

🔒 100% On-Device Privacy Commitment
DearTalk AI never transmits keystrokes, voice recordings, or translated text to external cloud servers. The app contains zero INTERNET permission, guaranteeing 100% offline, air-gapped privacy.

1. 100% On-Device Processing & Zero Data Collection

DearTalk AI is architected with a strict Zero-Data / Privacy-First Architecture:

  • Physical Network Isolation (Zero INTERNET Permission): The Application does NOT declare or request the android.permission.INTERNET permission in its Android manifest. It is technically impossible to transmit typed keystrokes, audio, or generated text to any external server.
  • Local Neural Inference: Google LiteRT models run 100% offline on your device using your phone's CPU, GPU, or Qualcomm NPU.
  • No Telemetry or Tracking: Contains zero advertising SDKs, zero user tracking libraries, and zero cloud analytics.

2. Permissions Requested and Purpose

Permission Purpose Data Handling
RECORD_AUDIO On-device real-time Speech-to-Text when explicitly triggered Processed in volatile RAM by local Android SpeechRecognizer API. Discarded immediately. Never saved as files, never transmitted.
VIBRATE Haptic vibration feedback on key presses Hardware trigger only (no data collected)
BIND_INPUT_METHOD Registers DearTalk AI as an active Android keyboard Android OS required system permission

3. Data Retention and Deletion (Google Play Data Safety)

  • No Cloud Backend: Because DearTalk AI operates with 0% network access, we do not store, sell, or retain any personal data.
  • Ephemeral RAM Life Cycle: Speech drafts and suggestions are held in volatile RAM and cleared immediately after use.
  • Complete User Control: Uninstalling the application or wiping app storage in Android Settings irreversibly erases all local settings.

4. Children's Privacy

DearTalk AI does not collect, process, or share personal information from anyone, including children under 13.

5. Open Source Transparency

DearTalk AI strictly complies with the Apache License 2.0 open source standard, providing transparent, secure, and purely on-device privacy with zero network dependencies.
