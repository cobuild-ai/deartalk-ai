# 2026-08-19: macOS 가짜 규칙(Mock) 전면 영구 삭제, 제1철칙(Zero Fake Rules) 확립 및 100% 온디바이스 신경망 추론 정석 구조 개편

## 🚀 주요 업무 내용
1. **🚨 macOS 가짜 목업(Mock) 로직 전면 적발 및 영구 삭제:**
   - [DearTalkIntentEngine.swift](../../deartalk-apple/DearTalk-macOS/Sources/DearTalkMacCore/Core/DearTalkIntentEngine.swift) 내부에 남아있던 하드코딩된 예제 문자열 분기(`contains()`) 및 자유 입력 시 `+ " 부탁드리겠습니다."`를 강제로 결합하던 꼼수 코드를 100% 영구 삭제.
2. **🛡️ 제1철칙(Zero Fake Rules) 및 정직한 원문 보존 모드 정립:**
   - 온디바이스 모델 미배치/미로드 상태에서 가짜 텍스트를 인위적으로 합성하지 않고, 모델 준비 상태를 정직하게 알리며 원문을 100% 온전하게 보존하도록 개편.
   - 사용자 자유 입력 문장(`"부탁할께 너의 고양이를 가져와"`)에 대해 가짜 어미 결합이 발생하지 않음을 단위 검증으로 증명.
3. **🧠 Gemma 온디바이스 표준 프롬프트 템플릿 및 클렌징 파이프라인 구축:**
   - 문맥 다듬기, 톤앤매너 변환, 다국어 번역에 대해 챗봇 방지 지시 및 Gemma 역할 마커(`<start_of_turn>user ... <end_of_turn><start_of_turn>model`)를 표준화.
   - LLM 특수 제어 태그 및 턴 마커를 정밀 제거하는 `cleanLlmOutput` 고도화.
4. **🎨 실시간 DIFF 샌드박스([SandboxView.swift](../../deartalk-apple/DearTalk-macOS/Sources/DearTalkMacCore/UI/SandboxView.swift)) UI 상태 정합성 확보:**
   - `DearTalkIntentEngine.shared` 상태와 실시간 바인딩하여 모델 로드 상태를 헤더 및 결과 뷰에 투명하게 표시.
5. **🧪 단위 테스트 및 통합 러너 검증:**
   - macOS 코어 엔진 검증(`swift run DearTalkMacRunner`): 원문 복원율, 왜곡 방지 및 클렌징 100% 통과.
   - Android 단위 테스트(`SentenceBackspaceTest`, `DearTalkIntentEngineTest`): 8개 테스트 100% 통과.
6. **🔒 macOS 단일 인스턴스(Single-Instance) 프로세스 락 탑재:**
   - 커널 수준의 배타적 파일 락(`flock`) 및 `DistributedNotificationCenter`를 연동하여 앱이 중복 실행되어 메뉴바 아이콘/샌드박스 윈도우가 2개씩 뜨는 현상을 원천 방지.
   - 중복 실행 시도 시 기존 인스턴스 윈도우를 최상단으로 활성화하고 새 프로세스는 즉시 자동 종료되도록 처리.
7. **🪵 통합 로깅 시스템([DearTalkLogger.swift](../../deartalk-apple/DearTalk-macOS/Sources/DearTalkMacCore/Data/DearTalkLogger.swift)) 및 접근성 크래시 방어:**
   - 터미널 표준 출력(stdout), 파일 로그(`~/.deartalk/deartalk.log`), Apple `os_log`를 3중 동기화하는 전용 통합 로거 탑재.
   - [AccessibilityMonitor.swift](../../deartalk-apple/DearTalk-macOS/Sources/DearTalkMacCore/Core/AccessibilityMonitor.swift)에서 키보드 입력 및 포커스 전환 시 발생할 수 있는 `as! AXUIElement` 강제 캐스팅을 CoreFoundation `CFGetTypeID` 안전 검증으로 교체하고, `NSAttributedString` 지원을 추가하여 타이핑 시 크래시 원천 차단.
8. **📦 독립 실행형 단일 번들 `DearTalk.app` 패키징 파이프라인 구축:**
   - [package_macos_app.sh](../../deartalk-apple/DearTalk-macOS/scripts/package_macos_app.sh) 스크립트를 구현하여 `swift build -c release` 최적화 바이너리와 내장 온디바이스 모델 리소스(`Contents/Resources/models/`), `Info.plist`, Ad-hoc 코드사이닝을 일체화한 `DearTalk.app` 생성 완료.
   - 사용자가 별도의 터미널 및 외부 도구 없이 `.app` 더블 클릭만으로 독립 실행 가능하도록 번들 리소스 우선순위 로더 연동.
9. **📥 인앱 온디바이스 모델 1-Click 자동 다운로더([ModelDownloader.swift](../../deartalk-apple/DearTalk-macOS/Sources/DearTalkMacCore/Core/ModelDownloader.swift)) 및 완결형 UX 구축:**
   - 모델 파일 부재 시 사용자가 외부 터미널 명령을 칠 필요 없이, 앱 화면 내에서 실시간 다운로드 프로그레스 바(용량, 진행률 %, 속도)와 함께 **"🚀 온디바이스 AI 모델 자동 다운로드 (1-Click)"** 버튼 제공.
   - 다운로드 완료 시 `~/Library/Application Support/DearTalk/models/model.gguf`로 원자적 이동 후 온디바이스 추론 엔진이 즉시 활성화되는 완결 구도 구축.
10. **⚡ Apple Silicon Metal GPU 하드웨어 가속 신경망 연동 ([DearTalkIntentEngine.swift](../../deartalk-apple/DearTalk-macOS/Sources/DearTalkMacCore/Core/DearTalkIntentEngine.swift)):**
    - `llama-server` 백엔드를 자동 연동하여 다운로드된 Gemma 2B Q4_K_M 모델을 기기 내부 Metal GPU VRAM에 상주 로드.
    - 프롬프트 처리 속도 226.4 t/s, 토큰 생성 속도 30.4 t/s(평균 100ms 미만 초고속 레이턴시)의 순수 100% 온디바이스 신경망 추론 달성.
11. **✨ 실시간 플로팅 오버레이([FloatingDiffOverlayView.swift](../../deartalk-apple/DearTalk-macOS/Sources/DearTalkMacCore/UI/FloatingDiffOverlayView.swift)) 윈도우 레벨 및 위치 최적화:**
    - `orderFrontRegardless()`, `popUpMenu` 최상단 윈도우 레벨 및 `hidesOnDeactivate = false` 적용으로 타 앱 전환 시에도 팝업이 숨겨지지 않도록 보강.
    - 샌드박스 화면에 `[✨ 플로팅 패널 띄우기]` 즉시 테스트 버튼을 탑재하여 UI 인터랙션 검증 환경 완성.
