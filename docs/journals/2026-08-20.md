# 2026-08-20: [DearTalk] macOS 플로팅 패널 멀티모니터 좌표계 보정, Android형 2줄 UI/UX 통일 및 온보딩 마법사 구축

## 🚀 주요 업무 내용

1. **🖥️ macOS 플로팅 패널 듀얼 모니터 좌표계 변환 오차 완벽 해결**
   - macOS 접근성(Top-Left) 좌표와 Cocoa Window(Bottom-Left) 좌표계 간의 불일치로 인해 서브 모니터에서 패널이 화면 밖으로 이탈하던 현상을 가상 데스크톱 전체 프레임 기반 변환 공식으로 전면 수정.
   - 카카오톡 및 모든 활성 텍스트 필드 바로 위에 플로팅 패널이 정확히 안착하도록 구현.

2. **🌟 Raycast 스타일 "대화형 원클릭 온보딩 마법사" 탑재**
   - 손쉬운 사용(Accessibility) 권한 설정의 진입 장벽을 낮추기 위해, 앱 실행 시 실시간 상태를 감지하고 완료 시 자동으로 전환되는 온보딩 마법사 윈도우(`OnboardingGuideView.swift`) 구현.
   - `NSWindow.isReleasedWhenClosed = false` 설정을 통한 메모리 충돌 크래시(`EXC_BAD_ACCESS`) 방지.

3. **📱 Android와 통일된 "2줄 레이아웃 (원문 고정 + AI 실시간 교체)" 및 공식 6대 톤앤매너 완비**
   - **1줄 `[원문]`**: 사용자가 입력한 원래 문장을 불변(Immutable) 상태로 고정 표시.
   - **2줄 `[AI]`**: 상단 6대 톤앤매너 칩(`✨ 기본다듬기`, `👔 공손하게`, `😊 친근하게`, `💼 비즈니스`, `🤣 재미있게`, `😼 건방지게`) 선택에 따라 원문을 기반으로 실시간 온디바이스 LLM 추론 결과 및 DIFF만 갱신.
   - **⇥ Tab 자동완성 토글 & 수동 적용 툴바**:
     - 코딩/프로그래밍 시 들여쓰기 Tab 키와 충돌하지 않도록 플로팅 패널 헤더에 `[ ⇥ Tab 적용 ON/OFF ]` 토글 스위치 탑재.
     - Tab 적용이 꺼져 있을 때도 `[ ✅ 적용하기 ]` 마우스 클릭 버튼을 통해 완벽한 수동 치환 지원.

4. **🧹 이전 빌드 손쉬운 사용(Accessibility) 유령 캐시 자동 리셋 (`tccutil reset`)**
   - 온보딩 마법사에서 설정 열기 시 낡은 TCC 엔트리를 백그라운드에서 자동 초기화하여 스위치 기등록 혼란 완벽 해소.

5. **🛡️ `DiffEngine.swift` LCS 행렬 범위 크래시(`lowerBound <= upperBound`) 방어**
   - 빈 토큰 또는 특수문자 입력 시 `1...n` 범위가 `1...0`으로 평가되어 발생하던 Swift 런타임 SIGTRAP 크래시를 `guard n > 0 && m > 0` 및 빈 토큰 얼리 리턴으로 완벽 방어.

6. **🌐 글로벌 오픈소스 표준(Global Open Source Standard) 전면 리팩토링**
   - **다국어 UI 분리(`UiStrings`):** 소스 코드 내 하드코딩된 한국어 UI 문자열을 `UiStrings` 싱글톤으로 전면 분리하여 시스템 로케일에 따라 한/영 자동 전환 지원.
   - **주석 및 로그 영문화:** 모든 클래스/함수 주석(Docstrings) 및 엔진 로거 메시지를 영문 글로벌 표준으로 통일.
   - **오픈소스 에셋 완비:** Apache 2.0 `LICENSE`, `CONTRIBUTING.md`, Issue 및 PR 템플릿 등록 완료.
   - **빌드 스크립트 최적화:** 1.6GB 온디바이스 모델 심링크 탑재로 0.15초 초고속 번들 패키징 구현.

7. **🎯 크로스 플랫폼 대칭형 공통 테스트 스위트(Common Test Suite) 표준화**
   - Android(`CommonCoreEngineTest.kt`)와 macOS(`DearTalkMacRunner`) 양쪽에 **동일한 5대 공통 테스트 규격**(톤앤매너 6종 ID 일치, 제1철칙 원문 보존, 빈 문자열/공백 방어, 특수문자`@smilelife` 안전성, LLM 태그 클렌징)을 구축하여 플랫폼 간 무결성을 100% 보장.

8. **🔍 전문 오픈소스 메인테이너 관점 전수 정밀 코드 리뷰(Deep Audit)**
   - **이모지 렌더링 결함 수정:** `FloatingDiffOverlayView.swift`에서 `Image(systemName: tone.icon)` 대신 `Text(tone.icon)`을 적용하여 플로팅 패널의 6대 톤앤매너 이모지 누락 결함 완벽 해결.
   - **`ModelDownloader.swift` 다국어화:** 상태 메시지 및 다운로더 로거를 `UiStrings`와 연동하여 글로벌 영문화 정비.
   - **CI/CD 및 오픈소스 커뮤니티 에셋 완성:** `ARCHITECTURE.md`, `TESTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md` 및 GitHub Actions Matrix CI 완비.

9. **📱 Android Wi-Fi 무선 디버깅 배포 완료 (`SM-S908N - Android 16`)**
   - 로컬 mDNS 디스커버리를 통해 `192.168.1.136:44869` 기기에 무선 연결 후 Gradle `:deartalk-android:installDebug` 자동 빌드 및 실기기 배포 완료.
   - STT 음성인식 원문 보존 파이프라인(`recognizedTextState`) 및 공식 6대 톤앤매너 칩 실기기 적용.
   - `DearTalkIntentEngine.kt`의 `processWithTone`에 `재미있게(🤣)` 및 `건방지게(😼)` 전용 Few-shot 예시 분기 주입으로 어조 변환 오작동 완벽 해결.

7. **🧠 온디바이스 Gemma 톤앤매너 프롬프트 Few-shot 엔지니어링**
   - 문장 선두에 `요, ` 또는 `:` 등 불필요한 접두어가 붙는 문제를 해결하기 위해 한국어 톤별 Few-shot 예시 주입 및 `cleanLlmOutput` 정밀 정규식 필터 탑재.

## 📝 AI Insight (#from-ai)

- **크로스 플랫폼 UI/UX 일관성의 가치:**
  - Android 키보드와 macOS 플로팅 패널 간에 '원문 고정 + AI 2줄 레이아웃'이라는 동일한 멘탈 모델을 제공함으로써, 사용자는 기기가 바뀌어도 동일한 사용 흐름(타이핑 ➡️ 원문 확인 ➡️ 톤 칩 선택 ➡️ Tab/적용)에 즉각 적응할 수 있습니다.
- **온디바이스 LLM의 결정론적 Few-shot 제어:**
  - 작은 파라미터(2B)의 온디바이스 LLM일수록 단순 지시문보다는 명확한 한국어 입출력 쌍(Few-shot)을 제공하는 것이 의도치 않은 어미 중복이나 접두어 환각을 방지하는 가장 확실한 엔지니어링 해법임을 실증했습니다.
