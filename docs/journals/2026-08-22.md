# 2026-08-22: 온디바이스 추론 파이프라인 고도화 & macOS/iOS/Android 멀티플랫폼 버전 및 사용설명서 통합 구현

## 🚀 주요 업무 내용
1. 📱 **iOS Core 추론 엔진 기능 고도화 (`deartalk-apple/DearTalk-iOS`)**
   - **온디바이스 LLM 루프백 추론 구현:** macOS와 동일한 방식의 로컬 HTTP 통신 기반 추론 연동([`DearTalkIntentEngine.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSCore/Core/DearTalkIntentEngine.swift))을 포팅하여, Mock 수준에 머물렀던 iOS Gemma 로컬 추론 동작을 완전하게 완성시켰습니다.
   - **로컬 LLM 서비스 자동 연동:** 시뮬레이터나 테스트 기기가 macOS의 로컬 Gemma/Ollama 서비스 인스턴스를 탐색해 NPU/GPU/CPU 상에서 순수 신경망 추론 결과를 받아올 수 있도록 127.0.0.1 루프백 연동 체계를 적용했습니다.
2. 🧪 **iOS QA 검증 러너 (`DearTalkIOSRunner`) 테스트 정합성 개선**
   - 모델이 로드되었을 경우 실제 AI 추론으로 인해 텍스트의 다듬기 처리가 정상적으로 발생함을 허용하도록 검증식을 개선하였습니다 ([`main.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSRunner/main.swift)).
   - 이로 인해 실제 로컬 모델이 활성화된 환경에서도 테스트 러너가 불필요하게 실패하지 않도록 안정성을 강화했습니다.
3. 📦 **Android/iOS 온디바이스 LLM 미설치/미준비 진단 및 원클릭 다운로드 고도화**
   - **Android 다운로더 구현 및 UI 고도화:** Android용 [`ModelDownloader.kt`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-android/src/main/java/ai/deartalk/android/agent/ModelDownloader.kt)를 순수 HttpURLConnection과 코루틴 StateFlow 기반으로 구현하여 비동기 다운로드 및 진행률 상태 조회를 제공하고, [`MainActivity.kt`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-android/src/main/java/ai/deartalk/android/MainActivity.kt)의 Compose UI에 원클릭 다운로드 카드와 로컬 감지 새로고침 기능을 연동했습니다.
   - **iOS/Android 엔진 로드 최적화:** 다운로드 완료 시 `detectAndInitOnDeviceModel()`을 트리거하여 UI 리프레시 없이 새로 설치된 로컬 모델을 즉시 적용하도록 하였으며, 안드로이드 엔진에 Compose 리액티브 UI를 지원하는 `isModelLoadedFlow`를 구축했습니다.
   - **iOS 다운로드 UI 포팅:** iOS의 [`ModelDownloader.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSCore/Core/ModelDownloader.swift)에 default URL 설정과 파일 이동 로직을 추가하고 [`IOSSandboxView.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSCore/UI/IOSSandboxView.swift)에 다운로드 전용 카드를 배치해 macOS 수준의 세련된 사용성을 포팅했습니다.
4. ⚙️ **macOS/iOS/Android 전 플랫폼 앱 버전(SemVer), 빌드 타임스탬프, 사용 설명(도움말) 화면 통합 개발**
   - **macOS 도움말 및 버전 정보 제공:** [`SettingsView.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-macOS/Sources/DearTalkMacCore/UI/SettingsView.swift)에 `TabView`를 적용하여 일반 설정과 정보/도움말을 탭으로 분리하고, 앱 이름/버전(SemVer)/빌드 타임스탬프(Info.plist 속성 기반 동적 감지) 및 상세 사용 방법(도움말) 카드를 구현했습니다.
   - **iOS 도움말 및 버전 정보 연동:** [`IOSSettingsView.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSCore/UI/IOSSettingsView.swift) 하단에 앱 버전과 빌드 타임스탬프 정보 섹션을 추가하고, 상세 도움말을 안내하는 `iOSUserGuideView` 화면을 내비게이션 링크로 연결하였으며, [`IOSSandboxView.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSCore/UI/IOSSandboxView.swift)의 툴바 우측 상단에 설정 기어 아이콘을 추가하여 접근성을 높였습니다.
   - **Android 도움말 및 버전 정보 고도화:** [`MainActivity.kt`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-android/src/main/java/ai/deartalk/android/MainActivity.kt)의 정보 카드에 `packageInfo.lastUpdateTime` 기반 동적 빌드 타임스탬프를 적용하고, 키보드 등록 및 AI 음성 입력 등 상세 작동 원리를 친절하게 서술한 사용 설명서(도움말) 카드를 추가로 연동했습니다.
   - **테스트 케이스 보강 및 정밀 검증:** macOS [`DearTalkMacRunner`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-macOS/Sources/DearTalkMacRunner/main.swift), iOS [`DearTalkIOSRunner`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSRunner/main.swift), Android [`UiStringsLocaleTest`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-android/src/test/java/ai/deartalk/android/pref/UiStringsLocaleTest.kt) 테스트 스위트에 다국어 버전 정보 및 도움말 리소스 정합성 검증용 어서션(Assertion)을 추가하고 빌드 및 전체 테스트 검증에 성공했습니다.

5. 🛠️ **macOS 온디바이스 런타임(llama.cpp/llama-server) 환경 자동 진단 및 원클릭 설치 구축**
   - **3단계 환경 진단 매니저 (`RuntimeSetupManager`):** 모델 파일(`.gguf`), Metal GPU 가속 런타임(`llama-server`), Homebrew 패키지 매니저, 로컬 데몬 서비스(11435 포트)의 헬스체크를 종합적으로 진단하는 매니저를 구현했습니다.
   - **Homebrew 기반 원클릭 백그라운드 자동 설치:** Homebrew가 설치된 PC에서 `brew install llama.cpp`를 비동기 프로세스로 실행하여 진행률 및 상태를 안내하고, 설치 완료 시 자동으로 엔진을 핫 리로드(Hot-Reload)하도록 구현했습니다.
   - **원클릭 터미널 명령 복사 및 직관적 UI:** [SandboxView.swift](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-macOS/Sources/DearTalkMacCore/UI/SandboxView.swift)와 [SettingsView.swift](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-macOS/Sources/DearTalkMacCore/UI/SettingsView.swift)에 3단계 진단 상태와 모델 다운로드, 런타임 설치, 터미널 복사, 환경 새로고침 카드를 완비하여 디버깅 없이도 일반 사용자가 원클릭으로 온디바이스 AI 환경을 완성할 수 있도록 구현했습니다.
   - **macOS 테스트 러너 정밀 검증:** [DearTalkMacRunner/main.swift](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-macOS/Sources/DearTalkMacRunner/main.swift)에 환경 진단 및 다국어 리소스 정합성 검증 테스트를 추가하고 100% 통과를 완료했습니다.

## 📝 AI Insight (#from-ai)
> [!NOTE]
> **멀티플랫폼 아키텍처의 정합성과 에뮬레이터 검증성 확보**
> 이번 개선으로 iOS 시뮬레이터 환경에서도 실제 macOS와 100% 동일하게 로컬 llama-server나 Ollama 기반의 Gemma 2B 온디바이스 추론을 수행할 수 있게 되었습니다. 이는 물리적 모바일 기기뿐만 아니라 개발 단계의 가상 머신 테스트에서도 온디바이스 NPU 추론 시뮬레이션을 수행하고, UI에 변경사항(Diff)이 올바르게 렌더링되는지를 안전하게 테스트할 수 있는 검증 신뢰도를 제공합니다.
>
> **사용자 환경 진단과 자율 설치 파이프라인의 완성**
> 온디바이스 AI 앱의 최대 장벽인 '초기 모델 배치 및 런타임 의존성 구성'을 인앱 자동 설치 흐름으로 완벽히 녹여냈습니다. 특히 모바일(Android/iOS)의 LiteRT/CoreML 모델 다운로더뿐만 아니라, 데스크톱 macOS의 Metal 가속 런타임(`llama-server` / `llama.cpp`) 미설치 상태까지 앱 스스로 진단하고 Homebrew 원클릭 설치 및 터미널 가이드를 제공함으로써, 개발자가 아닌 일반 사용자도 디버깅 없이 온디바이스 AI를 즉시 누릴 수 있는 강력한 편의성을 확보했습니다.
>
> **버전 관리 및 사용설명서 통합에 따른 유지보수 신뢰성 확보**
> macOS, iOS, Android 3대 모바일 및 데스크톱 플랫폼 모두에서 앱의 시맨틱 버전(SemVer) 및 빌드 타임스탬프를 동적으로 감지(Dynamic Detection)하여 표시하는 기능을 완성하여 향후 QA 배포 및 디버깅 시 환경 정합성을 손쉽게 판단할 수 있습니다. 또한, 각 플랫폼의 특성(macOS 탭 뷰, iOS 내비게이션 푸시, Android 스크롤 영역 카드 배치)에 가장 어울리는 UX 방식으로 도움말(사용 설명) 화면을 구축하여, 온디바이스 AI 사용이 생소한 일반 사용자의 진입 장벽을 완전히 해소하고 제품적 완성도를 달성했습니다.
