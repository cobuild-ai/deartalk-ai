# 2026-08-22: DearTalk-iOS/Android 온디바이스 추론 파이프라인 정밀화 및 인앱 모델 자동 설치 UI 고도화

## 🚀 주요 업무 내용
1. 📱 **iOS Core 추론 엔진 기능 고도화 (`deartalk-apple/DearTalk-iOS`)**
   - **온디바이스 LLM 루프백 추론 구현:** macOS와 동일한 방식의 로컬 HTTP 통신 기반 추론 연동([`DearTalkIntentEngine.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSCore/Core/DearTalkIntentEngine.swift))을 포팅하여, Mock 수준에 머물렀던 iOS Gemma 로컬 추론 동작을 완전하게 완성시켰습니다.
   - **로컬 LLM 서비스 자동 연동:** 시뮬레이터나 테스트 기기가 macOS의 로컬 Gemma/Ollama 서비스 인스턴스를 탐색해 NPU/GPU/CPU 상에서 순수 신경망 추론 결과를 받아올 수 있도록 127.0.0.1 루프백 연동 체계를 적용했습니다.
2. 🧪 **iOS QA 검증 러너 (`DearTalkIOSRunner`) 테스트 정합성 개선**
   - 모델이 로드되었을 경우 실제 AI 추론으로 인해 텍스트의 다듬기 처리가 정상적으로 발생함을 허용하도록 검증식을 개선하였습니다 ([`main.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSRunner/main.swift)).
   - 이로 인해 실제 로컬 모델이 활성화된 환경에서도 테스트 러너가 불필요하게 실패하지 않도록 안정성을 강화했습니다.
3. 📦 **Android/iOS 온디바이스 LLM 미설치/미준비 진단 및 원클릭 다운로드 고도화**
   - **Android 다운로더 구현 및 UI 고도화:** Android용 [`ModelDownloader.kt`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-android/src/main/java/ai/deartalk/android/agent/ModelDownloader.kt)를 순수 HttpURLConnection과 코루틴 StateFlow 기반으로 구현하여 비동기 다운로드 및 진행률 상태 조회를 제공하고, [`MainActivity.kt`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-android/src/main/java/ai/deartalk/android/MainActivity.kt)의 Compose UI에 원클릭 다운로드 카드와 로컬 감지 새로고침 기능을 연동했습니다.
   - **iOS/Android 엔진 로드 최적화:** 다운로드 완료 시 `detectAndInitOnDeviceModel()`을 트리거하여 UI 리프레시 없이 새로 설치된 로컬 모델을 즉시 적용하도록 하였으며, 안드로이드 엔진에 Compose 리액티브 UI를 지원하는 `isModelLoadedFlow`를 구축했습니다.
   - **iOS 다운로드 UI 포팅:** iOS의 [`ModelDownloader.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSCore/Core/ModelDownloader.swift)에 default URL 설정과 파일 이동 로직을 추가하고 [`IOSSandboxView.swift`](file:///Users/smilelife/Projects/deartalk-ai/deartalk-apple/DearTalk-iOS/Sources/DearTalkIOSCore/UI/IOSSandboxView.swift)에 다운로드 전용 카드를 배치해 macOS 수준의 세련된 사용성을 포팅했습니다.

## 📝 AI Insight (#from-ai)
> [!NOTE]
> **멀티플랫폼 아키텍처의 정합성과 에뮬레이터 검증성 확보**
> 이번 개선으로 iOS 시뮬레이터 환경에서도 실제 macOS와 100% 동일하게 로컬 llama-server나 Ollama 기반의 Gemma 2B 온디바이스 추론을 수행할 수 있게 되었습니다. 이는 물리적 모바일 기기뿐만 아니라 개발 단계의 가상 머신 테스트에서도 온디바이스 NPU 추론 시뮬레이션을 수행하고, UI에 변경사항(Diff)이 올바르게 렌더링되는지를 안전하게 테스트할 수 있는 검증 신뢰도를 제공합니다.
>
> **사용자 환경 진단과 자율 설치 파이프라인의 완성**
> 온디바이스 AI 앱의 최대 장벽인 '초기 모델 배치'를 인앱 자동 설치 흐름으로 완벽히 녹여냈습니다. 특히 Android와 iOS 플랫폼 모두 동일한 다운로드 모듈 시맨틱과 UI 구조를 갖게 되었으며, 다운로드와 동시에 수동 조작 없이 NPU/GPU Natively 가속 엔진이 신규 모델을 자동 감지(Hot-Reload)함으로써, 0% 네트워크 프라이버시 철칙을 완벽히 지키면서도 높은 사용성을 보장합니다.
